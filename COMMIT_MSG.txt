Replace hash routing with real paths (LearnKit URL pattern)

- Drop #/turkish/yapmak-etmek style URLs in favour of real
  paths so each lesson has its own shareable URL.
- New layout:
    /Language-Learning/                     - all-languages landing
    /Language-Learning/Turkish/             - language landing
    /Language-Learning/Turkish/yapmak-etmek - the lesson page
  Mirrors the structure used in forhad-h/learnkit
  (courses/<course>/index.html + pages/<page>.html).
- Each language folder now has lessons-data/<id>.js holding
  the pure data (window.LC_LESSONS.push), and a per-lesson
  HTML page that loads the data and the shared renderer.
- app.js no longer reads location.hash; pages opt into
  lesson vs landing view via data-view / data-lesson on body.
- Switching lessons from the sidebar is now a plain link
  click to the matching .html file.
